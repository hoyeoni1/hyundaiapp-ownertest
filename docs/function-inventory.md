# 쏘우카 — 사용 가능한 기능 목록 (운전 필수도 순)

- 작성: 2026-11-09. 새 설계의 출발점. "사용 가능"의 뜻: **플레이어가 실제 차에서 조작하면 앱이 Vehicle SDK로 알아챌 수 있다**(읽기 전용. 앱이 차를 제어하는 건 범위 밖)
- 근거: 크루즈브레이커 `docs/vehicle-data-findings.md`(Pleos 에뮬레이터 2.1.0, Vehicle SDK 2.3.2, 2026-10-22~29 실측). "절"은 그 문서 절 번호
- 상태: ✅ 리스너 수신 + 콘솔 재현 실측 / ⚠ 조회(getter)만 또는 조건부 / ❓ SDK는 되지만 콘솔 재현 미확인 / ❌ 불가
- 전제: 앱은 정차(기어 P) 전용. 기어 D·차속·크루즈처럼 주행이 필요한 것은 "감지는 되지만 게임 안에서 시키기 어려움"으로 표시

## 7. 한눈에 — 게임에 바로 쓸 수 있는 조작 (✅만)

| 분류 | 조작 |
|---|---|
| 주행 조작 | 좌/우 방향지시등, 전조등(하향), 상향등, 미등, 앞 와이퍼 켜기/끄기, 앞유리 제상, 뒷유리 열선, 브레이크, 핸들 각도, 기어 P 확인 |
| 출입·시야 | 창문 4개 올리기/내리기, 창문 잠금, 중앙 잠금/해제, 문 4개 열기/닫기, 실내등 |
| 공조·쾌적 | 공조 전원, A/C, 온도, 풍량, 내/외기, 시트 열선(운전석 실측), 핸들 열선, 앰비언트 색 |
| 전기차 | 충전구 열기 |
| 읽기 | SoC, 주행가능거리, 누적거리, 내비 위치·경로·즐겨찾기 |
| 출력 | TTS 음성 |

조건부로 쓸 수 있는 것(⚠·❓, 실측 30분이면 확정): 안전벨트, 뒷 와이퍼, 와이퍼 AUTO, 풍향, 트렁크·보닛, 시트 통풍, 미러 열선, 독서등 개별, 다른 좌석 열선, VIN, 실내·외기 온도.

쓸 수 없는 것(❌): 비상등, 경적, EPB·오토홀드, 차일드 락, 안개등, 주행 모드, 가속 페달, 시트 메모리, 타이어 공기압, 경고등, 연료·연비·트립, 미러 접기·각도.
