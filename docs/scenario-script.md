# 오너테스트 시나리오 v1.2 — 아포칼립스 생존 훈련 (검토용)

- 작성: 2026-11-09 (v1.2 — 이민하 정리: 신호에 올바르게 답하면 클리어, 신호는 마지막. 괴물은 기둥과 무관하게 일정 시간 뒤 랜덤, 기둥을 안 봤으면 게임 오버)
- 조작: **실내등 · 핸들 열선 · 앞유리 제상 · 전조등 · 브레이크 · 방향지시등 좌/우** (+ 시작의 문 잠금, 결말의 문 열기). 전부 Vehicle SDK 읽기
- 시작: 플레이어가 실제로 문을 잠그면 시작. 이야기 속에서는 갇힌 채 깨어남
- 화면: 1인칭, 어두운 차 안. 정면 → 왼쪽·오른쪽·룸미러 확대·핸들 확대. 왼쪽 → 왼쪽 사이드미러 확대. 오른쪽 → 오른쪽 사이드미러 확대
- 결말: 차가 아무것도 모르는 플레이어를 위험한 세상에 내보내기 전에 훈련시키려고 가둔 것. 성공적인 생존을 기원하며 끝
- 표기: 🖥 화면 / 🎧 소리 / 🔊 차의 음성(결말·조기 탈출에만) / ✅ 차량 신호 판정 / ⏱ 시간 처리 / 📖 설명서 카드

## 구조 한눈에

```
시작(문 잠금) ── 시계 시작
  ├─ 조사 ① 핸들 확대 ──실내등 ON──► 열 감응지(열 표시·그을림) + 야광 쪽지(태양·달)
  │        ├─ 열 감응지 ──핸들 열선──► "왼쪽에서 신호가 오면 답해라. 그러면 아침이다. (아래 쪽지에 계속)"
  │        └─ 야광 쪽지 ──실내등 10초 ON → OFF──► 달 + ◀ ◀ ▶
  ├─ 조사 ② 앞유리 ──제상 + 전조등──► 기둥 "그것은 빨간 불빛을 무서워해"
  │
  ├─ [이벤트 B: 괴물] 시작 후 일정 시간이 지나면 랜덤하게, 조사와 무관하게 온다
  │        브레이크 8초 → 격퇴 / 25초 안에 못 쫓으면 게임 오버 (기둥을 안 봤으면 힌트도 없다)
  │
  └─ [이벤트 A: 왼쪽의 신호] 마지막. 두 쪽지 ∧ 기둥 ∧ 괴물 1회 격퇴 뒤에만 온다
           ◀ ◀ ▶ 로 답하면 ──► 클리어(새벽, 첫 목소리, 문 열기)
```

조사 ①②는 순서가 없다. 괴물은 시간이 데려오고, 신호는 준비가 끝난 플레이어에게만 온다.

## 시점

| 시점 | 들어가는 법 | 보이는 것 |
|---|---|---|
| 정면 | 기본 | 앞유리(김·바깥), 대시보드, 룸미러(작게), 핸들(작게) |
| 핸들 확대 | 정면에서 핸들 탭 | 핸들 림의 **열 감응지**, 클락션 패드의 **야광 쪽지**, 레버 둘(실제 방향지시등·전조등 상태 표시). 실내등이 꺼져 있으면 "어두워서 보이지 않는다" |
| 룸미러 확대 | 정면에서 룸미러 탭 | 차 뒤. 어둠. 괴물이 오면 여기에. 브레이크를 밟으면 뒤가 붉게 |
| 왼쪽 | 정면에서 ← | 운전석 창, 왼쪽 사이드미러(작게) |
| 왼쪽 사이드미러 확대 | 왼쪽에서 미러 탭 | B3로 올라가는 경사로. 신호가 오면 손전등이 여기에 |
| 오른쪽 | 정면에서 → | 조수석 창, 오른쪽 사이드미러(작게) |
| 오른쪽 사이드미러 확대 | 오른쪽에서 미러 탭 | 기둥과 벽. 버려진 카트. 아무 일도 없다 |

## 시작

🖥 S1. 검은 바탕 한 줄: **"문을 잠그면 시작합니다."** 아래 작게: 화면 속 차는 지금 당신이 앉은 차를 그대로 비춥니다 / 앱은 문을 잠그지 않습니다 / 언제든 나갈 수 있습니다.
✅ 도어 잠금 false → true
🎧 철컥. 암전 5초. 🎧 멀리서 금속이 긁히는 소리, 정적.
🖥 정면. 깜깜하다. 앞유리는 뿌옇고 너머는 더 어둡다. 아무 글도 없다. (여기서 괴물 시계가 돈다)

## 조사 ① — 핸들 (실내등 → 핸들 열선 / 실내등 10초 → 끄기)

### 어두울 때

🖥 핸들 확대: 림과 클락션 패드에 무언가 붙어 있는 윤곽. 탭하면 **"어두워서 보이지 않는다."**
**추리** 빛이 필요하다. 머리 위 실내등.

### 실내등을 켜면

✅ 실내등 ON → 🖥 차 안이 보인다. 핸들 확대:
- **열 감응지**(림에 테이프로): 하얗다. 구석에 작은 **열 표시**(핸들 열선 버튼의 그림 — 핸들 위로 피어오르는 물결 선). 가장자리에 희미하게 **불에 그을린 흔적**. 탭하면 "감열지. 구석에 열 표시 하나. 글씨는 없다."
- **야광 쪽지**(클락션 패드에): 위쪽에 **선명한 태양**과 **희미한 달**. 아래는 빈칸. 탭하면 "태양은 진하고 달은 흐리다. 아래는 비어 있다."

### 열 감응지 → 핸들 열선

**추리** 열 표시 + 그을림 = 열에 반응하는 종이. 같은 그림이 붙은 스위치가 핸들 열선.
✅ 핸들 열선 ≥ 1 → 🖥 10초에 걸쳐 종이가 갈색으로 변하며 글씨:

> 왼쪽에서 신호가 오면 답해라.
> 그러면 아침이다.
> (아래 쪽지에 계속)

글씨는 열선을 꺼도 남는다.
**얻는 것** 왼쪽에서 신호가 온다. 답하면 끝난다. 답은 아래 쪽지에.
📖 **핸들 열선** — 버튼 위치, 켜고 끔.

### 야광 쪽지 → 실내등 10초 → 끄기

**추리** 진한 태양, 흐린 달 = 빛을 쬐면 어둠에서 보인다. 실내등을 켜 두었다가 끈다.
✅ 실내등 ON 10초 이상 연속 → ✅ 실내등 OFF → 🖥 어둠 속에서 쪽지가 빛난다: **달**, 그 아래 **◀ ◀ ▶**. 30초 뒤 서서히 꺼진다(다시 충전하면 다시 보인다).
(10초 전에 끄면 아무것도 안 보인다)
**얻는 것** 응답 신호 ◀ ◀ ▶.
📖 **실내등** — DOOR/ON/OFF, 독서등, 켜 둔 채 내리면 방전.

## 조사 ② — 앞유리 (제상 + 전조등)

🖥 정면: 앞유리가 뿌옇다. 탭하면 "뿌옇다. 밖이 안 보인다." 전조등만 켜면 뿌연 빛만 번진다. 제상만 켜면 걷히지만 어둡다.
**추리** 김을 걷고, 비춘다. 순서는 상관없다.
✅ 제상 ON ∧ 전조등 ON → 🖥 김이 걷히고(10초) 빛줄기 끝에 기둥. 스프레이 글씨 **한 줄**:

> 그것은 빨간 불빛을 무서워해

전조등을 끄면 어두워지지만, 읽은 글은 정면 화면 구석에 작은 메모로 남는다.
**얻는 것** "그것"이 있다. 빨간 불빛을 무서워한다. — 괴물을 쫓는 유일한 단서
📖 **앞유리 제상** — 버튼 하나로 A/C·외기 자동. **라이트 스위치** — OFF/AUTO/미등/전조등.

## 이벤트 B — 괴물 (브레이크) · 시간이 데려온다

| 항목 | 내용 |
|---|---|
| 시작 조건 | 없음. 시작 후 **90초 + 0~60초(랜덤)** 에 첫 등장. 조사를 했든 안 했든 온다 |
| 이후 간격 | 격퇴 뒤 60~150초 랜덤. 이벤트 A(신호)가 진행 중일 때는 오지 않는다. 클리어하면 끝 |
| 등장 | 🎧 긁는 소리가 뒤에서, 점점 가까이. 🖥 어느 시점에 있든 화면 가장자리가 어두워지고 룸미러(작게)에 움직임. 룸미러 확대: 어둠 속에서 큰 윤곽이 천천히 다가온다. 얼굴은 없다 |
| 정답 | ✅ 브레이크 ON → 🖥 룸미러 확대: 뒤 벽과 바닥이 **붉게** 물든다. 윤곽이 멈추고 물러선다. 🎧 긁는 소리가 멀어진다 |
| 격퇴 | 브레이크 **8초** 연속 유지(떼면 윤곽이 다시 다가오고, 유지 시간은 처음부터) → 윤곽이 어둠으로 사라진다. 📖 **브레이크** 카드(브레이크등은 밟는 동안만, 시동·기어 변경 전 브레이크) |
| ⏱ 힌트 (기둥을 **본** 경우만) | 10초: 정면 구석 메모의 "그것은 빨간 불빛을 무서워해"가 한 번 깜빡인다 / 18초: 메모 아래 "차에서 빨간 불이 나는 곳은 뒤다." |
| ⏱ 힌트 (기둥을 **안 본** 경우) | 없다. 무엇을 해야 하는지 알 길이 없다 |
| ⏱ 등장 후 25초, 브레이크 없음 | **게임 오버.** 🖥 룸미러가 윤곽으로 꽉 찬다 → 🎧 쿵 → 암전 → "…" 3초 → "실패" → [다시] |
| [다시] | 본 쪽지·기둥은 그대로. 괴물만 사라진 상태에서 이어진다. 괴물 시계는 다시 90초+랜덤. 기둥을 안 본 채 죽었으면 [다시] 직후 정면 아래에 한 줄: "앞을 봐야 한다." 횟수는 결과에 "다시 N번" |
| 전조등·실내등 | 괴물과 무관. 켜져 있어도 된다 |

## 이벤트 A — 왼쪽의 신호 (방향지시등) · 마지막

| 항목 | 내용 |
|---|---|
| 시작 조건 | 열 감응지 글씨 ∧ 야광 쪽지 화살표 ∧ 기둥 글씨 ∧ 괴물 1회 이상 격퇴 — 전부 갖춘 뒤 **20~60초 랜덤** |
| 신호 | 🎧 아무 소리 없음. 🖥 어느 시점에 있든 왼쪽 가장자리가 두 번 희게 깜빡인다. 왼쪽 사이드미러 확대: B3 경사로에서 손전등이 **세 번** 깜빡이고 멈춘다. 10초마다 반복, 총 40초. 이 동안 괴물은 오지 않는다 |
| 정답 | ✅ 방향지시등 LEFT → OFF → LEFT → OFF → RIGHT → OFF. 켜 두는 시간은 자유(원터치 3회 점멸도 한 번으로 침). 사이에 다른 방향이 끼면 처음부터 |
| 성공 = 클리어 | 🖥 핸들 확대의 레버 화살표가 실제로 깜빡인다. 미러 속 손전등이 **길게 한 번**(받았다). 손전등이 경사로 위를 가리키고 꺼진다. 📖 **방향지시등** 카드(원터치 3회, 3·5·7 설정) → **결말** |
| 틀렸을 때 | 손전등이 **짧게 두 번**(아니다). 이벤트 종료. 30~90초 뒤 다시 온다. 횟수 제한 없음 |
| ⏱ 40초 안에 응답 없음 | 손전등이 꺼진다. 30~90초 뒤 다시 온다. 벌 없음 |
| ⏱ 힌트 | 두 번 놓치거나 틀리면, 다음 신호부터 신호가 오는 동안 정면 구석 메모에 ◀ ◀ ▶ 가 작게 함께 뜬다. 네 번째부터는 핸들 확대의 왼쪽 레버가 희미하게 빛난다 |

## 시간 처리 (조사 구간 — 게임 오버 없음, 힌트만)

일정 시간 진전이 없으면 정면 화면 아래에 한 줄이 떴다 사라진다. 상황 묘사로, 조작 이름은 마지막 단계에만. 벌 없음, 횟수만 결과에.

| 상태 | ⏱ | 힌트 문구 |
|---|---|---|
| 아직 아무것도 안 봄 | 60초 / 120초 | "어둡다. 손 닿는 곳에 불이 있을 것이다." / "머리 위." |
| 실내등은 켰는데 핸들 확대를 안 봄 | 60초 | "핸들에 뭔가 붙어 있다." |
| 열 감응지를 봤는데 열선을 안 켬 | 90초 / 180초 | "가장자리가 그을렸다. 열이 닿았던 자리다." / "핸들을 데우는 스위치가 있다." |
| 야광 쪽지를 봤는데 충전→끄기를 안 함 | 90초 / 180초 | "태양은 진하고 달은 흐리다. 빛을 쬔 뒤의 어둠." / "실내등을 켜 두었다가 끈다." |
| 앞유리를 탭했는데 제상·전조등 둘 다 안 됨 | 90초 | "뿌옇고, 어둡다. 둘 다 해결해야 보인다." |
| 둘 중 하나만 됨 | 60초 | (제상만) "걷혔지만 어둡다." / (전조등만) "빛이 김에 번진다." |
| 기둥을 안 본 채 게임 오버 → [다시] | 즉시 | "앞을 봐야 한다." |
| 조사 ①②·격퇴를 다 했는데 신호가 아직 안 옴 | — | 힌트 없음(랜덤 대기 중). 열 감응지의 "왼쪽에서 신호가 오면"이 기다릴 이유다 |

## 결말 (신호에 올바르게 답한 직후)

🖥 손전등이 꺼지고 5초. 앞유리 너머가 아주 조금 밝아진다 — 새벽.
🎧 **이 차에서 처음 듣는 목소리.** 스피커에서, 차분하게.

🔊 "문은 내가 잠갔어."
(3초)
🔊 "오늘 밤은 연습이었어. 밖은 진짜야."
(2초)
🔊 "살아남아."
🎧 철컥(연출).
🔊 "문 열어도 돼."

✅ 운전석 문 열림 > 0 → 🖥 문 너머로 새벽빛. 결과 화면.
🔊 "행운을."

🖥 **성공** — 시간, 실패 N번, 힌트 N번, 배운 조작 6개(실내등·핸들 열선·앞유리 제상·전조등·브레이크·방향지시등)

## 분기

| 상황 | 처리 |
|---|---|
| 결말 전에 문을 열었을 때 | 🖥 문이 열린다. 🔊 (처음 듣는 목소리) "아직이야." 🎧 철컥. [다시 타기](문을 닫으면 활성, 상태 그대로) [끝내기]. 벌 없음 |
| 기어가 P를 벗어났을 때 | 회색 시스템 화면(이야기 밖): "차가 움직이면 훈련은 멈춥니다. P로 두면 이어집니다." |
| 실내등이 켜진 채 시작 | 핸들 확대가 바로 보인다. 야광 쪽지는 10초 충전 뒤 끄면 보인다 |
| 제상·전조등이 켜진 채 시작 | 기둥이 바로 보인다. 괴물 시계는 그대로 90초+랜덤 |
| 핸들 열선이 없는 차 | 열 감응지는 실내등을 켠 채 60초 두면 "실내 온기에 천천히" 드러난다. 카드는 "이 차엔 없음" |

## 단서와 회수

| 질문 | 단서 | 결말 |
|---|---|---|
| 누가 가뒀나 | 쪽지·기둥 글씨의 같은 손 | "문은 내가 잠갔어." |
| 왜 | "답하면 아침이다" — 아침까지 여기 있어야 했다 | 훈련. "아무것도 모른 채 나가려고 했지" |
| 밖은 무슨 일 | 기둥("그것"), 뒤의 것, 손전등(생존자, B3) | 밖은 진짜. 오늘 밤의 것들만 차가 그린 것 |

## 시연 순서 (에뮬레이터 콘솔 = 손)

| 순서 | 콘솔 | 화면 |
|---|---|---|
| 0 | `gear?gear=Park`, `body?doors_locked=false`, 실내등·전조등·제상 OFF, `steering-wheel-heat?level=0`, `controls?brake=0`, `turn-signal?mode=Off` | S1 |
| 1 | `body?doors_locked=true` | 암전 → 어두운 차 안. 핸들 확대: "어두워서 보이지 않는다" |
| 2 | `body?cabin_light=true` | 열 감응지(열 표시·그을림), 야광 쪽지(태양·달) |
| 3 | `steering-wheel-heat?level=2` | "왼쪽에서 신호가 오면 답해라. 그러면 아침이다." |
| 4 | (10초 뒤) `body?cabin_light=false` | 달 + ◀ ◀ ▶ |
| 5′ | (게임 오버 시연: 기둥 전에 괴물) 브레이크 없이 25초 | "실패" → [다시] → "앞을 봐야 한다." |
| 5 | `hvac?front_defroster=true` → 전조등 ON | 기둥 "그것은 빨간 불빛을 무서워해" |
| 6 | (괴물 등장 시) `controls?brake=50` (8초) → `=0` | 룸미러 붉게 → 윤곽 사라짐 |
| 7 | (신호 등장 시) `turn-signal?mode=BlinkLeft` → `Off` → `BlinkLeft` → `Off` → `BlinkRight` → `Off` | 손전등 길게 → 새벽 → 첫 목소리 |
| 8 | `body?door_fl=true` | 새벽빛 → 성공 |

개발 메뉴: 괴물 첫 등장 90초를 15초로, 신호 대기를 10초로 줄이는 시연 옵션.
