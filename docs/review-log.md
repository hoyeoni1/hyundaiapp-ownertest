# 오너테스트 검토 반복 기록 (v0.5 → v0.6)

- 작성: 2026-11-08. 이민하 지시: "직관적으로 플레이할 수 있는지, 흥미가 있을지, 어색한 부분 없는지, 그 외에도 퀄리티 괜찮은지 전체적으로 검토하면서 개선하는 과정 많이 반복해."
- 방법: 같은 설계를 관점을 바꿔 가며 처음부터 끝까지 "플레이"하고, 걸린 것을 적고, 고친 뒤 다음 관점으로 넘어갔다. 고친 결과는 [scenario-script.md](scenario-script.md) v0.6에 반영.

## 1회차 — 처음 하는 플레이어 (직관성)

| 걸린 것 | 왜 문제인가 | 고친 것 |
|---|---|---|
| S1 "졸음쉼터…" 인데 기둥 표지는 "B4" | 졸음쉼터엔 지하 4층이 없다. 설정이 서로 어긋남. 실제 플레이어가 있을 확률이 가장 높은 곳은 아파트 지하주차장 | 장소를 **지하주차장 B4**로. v0.5의 와이퍼 퍼즐은 비가 필요 없으므로 야외일 이유가 사라짐 |
| "잠깐 눈을 붙이려면 문을 잠그세요" | 지하주차장에서 왜 자나. 설명이 필요한 설정은 빼는 게 낫다 | S1은 **"시작하려면 문을 잠그세요."** 한 줄. 암전 → 02:13 → 그림이 분위기를 만든다 |
| "진짜 스위치를 눌러야 한다"는 걸 어떻게 아나 | 폰 방탈출 플레이어는 그림 속 제상 버튼을 탭한다. 반응이 없으면 막힌다. 핵심 장치가 발견되지 않을 위험 | ① S1에 한 줄: "화면 속 차는 지금 당신이 앉은 차를 그대로 비춥니다." ② 그림 속 스위치를 탭하면 흔들리며 **처음 한 번만** "그림이다. 진짜는 손 닿는 곳에 있다." ③ 시작 자체가 실제 잠금 → 화면 반응이라 첫 60초 안에 장치를 몸으로 배운다 |
| 장면을 넘길 수 있는지 모른다 | — | 양쪽 끝에 화살표 상시. 첫 장면에서 한 번 깜빡임 |
| VIN 플레이트가 처음부터 보인다 | 코드패드 "내 이름" + 번호판이 처음부터 있으면 영리한 플레이어가 끝 4자리를 바로 넣어 **퍼즐 4~7을 건너뛴다**. 학습 내용이 통째로 빠짐 | 플레이트 위에 **주차 스티커**가 붙어 있다(아파트 주차 스티커는 실제로 앞유리 하단에 붙는다). 긁어내야 보인다 |
| 도어 포켓의 동전이 쓸 데가 없다 | 방탈출에서 쓸모없는 아이템은 신뢰를 깎는다 | **동전으로 스티커를 긁는다.** 모든 아이템에 용도가 생김 |
| 폴라로이드가 분위기용 | 같은 이유 | 사진 속 센터 콘솔에 **시트 열선 표시등이 켜져 있다** → 영수증 퍼즐의 두 번째 단서(첫 번째는 전단지 뒷면) |

## 2회차 — 흥미 (긴장과 보상의 배치)

| 걸린 것 | 고친 것 |
|---|---|
| 중반(퍼즐 4~7)이 작업처럼 느껴질 수 있다 | 각 퍼즐의 끝에 작은 발견을 둔다: 전단지 뒷면 메모 / 충전구 덮개 안의 열쇠 / 폴라로이드 "네 뒤에서" / 영수증의 "운전자: 점검 요망". 보상 없이 끝나는 퍼즐이 없게 |
| 범인의 존재감이 쪽지뿐 | **시계가 02:13에서 멈춰 있다.** 주차권의 입차 시각도 02:13. 게임 내내 안 움직이다가 절정에서 목소리가 끝나면 02:14로 넘어간다. 말 없이 누르는 장치 |
| 절정의 대사가 쪽지와 안 이어짐 | 절정에서 쪽지 셋을 한 문장으로 회수: "매일 날 보면서 제대로 본 적도 없고, 내 안에 뭘 꽂는지도 몰랐지." |
| 결말 대사 순서 | "문을 열고 나가면 돼"가 문이 열린 뒤에 나오면 이상하다. **"마지막 장이야. 읽고 나면, 문을 열고 나가면 돼."** → 플레이어가 손잡이를 당김 → "처음부터 열렸어. 앞으로 잘 지내보자고." |

## 3회차 — 어색함 (한 줄씩 소리 내어 읽기)

| 걸린 것 | 고친 것 |
|---|---|
| 쪽지 C "넌 거기에 뭘 넣는지만 알지" | 다른 뜻으로 읽힐 수 있다 | "열쇠는 내 입 안에 있어. 매주 거기에 뭔가를 꽂으면서, 들여다본 적은 없지." (충전을 가리키는 게 분명해짐) |
| 영수증 "차대번호: ····· (앞유리 하단 왼쪽 참조)" | 정비 영수증이 "참조"라고 쓰지 않는다 | 서식처럼: "차대번호: ··········· / 확인: 앞유리 플레이트" |
| 문에 코드패드가 왜 있나 | 장면 ② 설명에 한 줄: "문에 작은 전자 자물쇠가 덧붙어 있다. 라벨: 내 이름." (범인이 단 것) |
| 송풍구에 영수증을 대면? | 플레이어가 먼저 떠올릴 수 있는 열원. 감지 불가 | 송풍구 핫스팟: "바람이 미지근하다. 글씨가 나올 만큼은 아니다." — 막지 않고 돌린다 |
| 어두워서 못 읽을 때 | "어두워서 읽을 수 없다"만 있으면 왜인지 모를 수 있다 | 처음 한 번만 "어두워서 읽을 수 없다. 불이 필요하다." 그 뒤는 짧게 |
| 와이퍼가 움직이는 동안 창밖으로 손을 내밀면 | "와이퍼가 움직이고 있다. 손을 내밀 수 없다." → 끄는 것도 배운다 |

## 4회차 — 현대차 심사위원 (브랜드·안전)

| 걸린 것 | 고친 것 |
|---|---|
| "누가 날 여기 뒀나"가 위협적으로 읽힐까 | 쪽지 4장 어디에도 위협이 없다. 코드패드는 그림이고, 결말·조기 탈출에서 "처음부터 열렸어"를 반드시 말한다. 유지 |
| 실제 VIN을 화면에 | 읽기만, 저장·전송 없음, 입력은 끝 4자리, 결과 화면에 안 남김. 유지 + PRD 리스크에 명시 |
| 마른 유리에 와이퍼 | 몇 초면 되고, 설명서 페이지에서 MIST(워셔액)를 함께 안내. 유지 |
| 지하주차장에서 내연기관 시동 ON | S1의 ACC 권장 문구 유지 |

## 5회차 — 게임 디자이너 (퍼즐 논리·막힘)

| 걸린 것 | 고친 것 |
|---|---|
| 막힐 수 있는 지점 7개: 넘기기 / 진짜 스위치 / B4→기둥 / 입→충전구 / 열→시트 / 스티커→동전 / 내 이름→VIN | 각 지점에 힌트 3단계를 **문장으로** 써 둠(아래 시나리오 "힌트" 표). 누르기 전엔 없음 |
| 퍼즐 순서가 너무 고정인가 | 조사(쪽지·주차권·동전)와 퍼즐 1·2·4·5는 서로 독립이라 어떤 순서로도 된다. 6→7→8만 의존. 적당한 자유도 |
| 실제 차에 열선이 없으면(기본 트림) | capability로 확인 → 영수증은 시트에 20초 놓으면 "체온에 천천히…"로 드러나게. 페이지는 "이 차엔 없음" |
| 실제 차에 충전구가 없으면 | 쪽지 C 문구를 바꾸고 키는 동전 아래. 퍼즐 없이 획득 |
| 글로브박스 코드를 모른 채 설명서 없이 "입"을 풀 수 있나 | 쪽지 C만으로는 어렵다. 설명서 책갈피 「충전구 열기」가 글로브박스 안에 있으므로 자연히 퍼즐 3 뒤에 풀린다. 의존성이 아이템으로 생김 — 좋다 |

## 2회전 — v0.6을 다시 처음부터 (순서 건너뛰기·논리 구멍)

| 걸린 것 | 왜 문제인가 | 고친 것 |
|---|---|---|
| 동전이 처음부터 있어서 스티커를 바로 긁을 수 있다 | 설명서(퍼즐 3)의 「차대번호」 페이지를 본 플레이어가 곧장 VIN을 "내 이름"에 넣으면 퍼즐 4~7을 건너뛰고 절정에 간다. 그때 설명서조차 없을 수도 있어 "마지막 장이야"가 성립하지 않는다 | **긁는 도구를 동전에서 기계식 키로.** 키는 퍼즐 5(충전구, 설명서 필요) 뒤에만 생기므로 VIN은 그 전엔 어디에도 보이지 않는다. 동전은 삭제(아이템 9개). 내연기관 분기는 키가 도어 포켓에 있어 일찍 긁을 수 있지만, "내 이름"=차대번호의 연결은 설명서·영수증에 있어 건너뛰기는 드물다 — 리스크로만 기록 |
| 영수증이 "차대번호: ·····"로만 가리면 플레이트를 보러 갈 이유가 약하다 | — | "차대번호: KMH······ (뒷자리 판독 불가) / 확인: 앞유리 플레이트" — 앞부분은 보여 주고 뒷자리만 플레이트로 보낸다 |
| 제상을 끄면 김이 어떻게 되나 | 거울 규칙이 불명확 | 끄면 30초에 걸쳐 천천히 다시 낀다. 다시 켜면 걷힌다 |
| 뒷좌석 장면이 쪽지 하나뿐 | 다시 갈 이유가 없다 | 폴라로이드를 얻은 뒤 뒷좌석 가운데를 탭하면 "사진과 같은 자리다." — 되돌아간 플레이어에게 작은 보상 |
| 결말의 "처음부터 열렸어"가 그림 속 "자물쇠가 막고 있다"와 어긋나나 | — | 어긋나지 않는다. 전자 자물쇠는 그림 속 문의 것이고, "처음부터 열렸어"는 진짜 문. 결말에서 그림 속 문도 함께 열린다 |
| 절정 뒤 페이지를 안 읽고 바로 손잡이를 당기면 | — | 문이 열리면 결말. 페이지는 어쨌든 수집된다. 막지 않는다 |

## 8회차 — 마지막으로 처음부터 다시 플레이 (남은 것)

- 02:13이 멈춰 있다는 걸 눈치채는 플레이어는 절정 전에 "시간이 안 간다 → 이 차 안의 시계" 로 범인을 짐작할 수 있다. 공정한 단서로 둔다(반전 뒤 회수).
- 조기 탈출 뒤 [다시 타기]는 조사 상태를 그대로 둔다. 문을 닫아야 활성.
- 결과 화면에 "설명서는 진짜 글로브박스에도 있다" 한 줄 — 농담이 아니라 안내로.
- 남은 확인: 실제 차종에서 안쪽 손잡이가 한 번에 열리는지 두 번인지(페이지 문구), 조수석 열선 콘솔 항목명, 전조등 콘솔 항목명.
